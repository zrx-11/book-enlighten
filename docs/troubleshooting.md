# 排错表

按症状查。每条都写了"怎么确认"和"怎么修"，别只照着改，先确认症状对得上。

## 抽取

| 症状 | 怎么确认 | 怎么修 |
|---|---|---|
| 输出全是 `cid:`、`□`、`(cid:123)` | 打开 `_work/raw/*.txt` 搜 `cid:` | 扫描件或字体加密，文本层不可用。改用 Read 按页读 PDF 截图，人工抄公式。或者先用 OCR 过一遍再校对 |
| 抽出 0 字符 | 文件是不是真 PDF，`file xx.pdf` 看一下 | 有的 PDF 是下载失败的 HTML 改名。重新下 |
| 章节切出 30 多个标题 | 对照原书目录 | 正文里的小节标题被当成了章标题。手工修 `_work/结构地图.md`，切分以结构地图为准 |
| DOCX/EPUB 报缺库 | 报错信息里点名了模块 | `pip install python-docx ebooklib` |

## 构建

| 症状 | 怎么确认 | 怎么修 |
|---|---|---|
| 运行 `build_handbook.py` 说发现 0 本书 | 看根目录各子目录 | 每个书目录里必须有 `manifest.json` **并且**有至少一个 `*.html`。缺一个都不算书 |
| 页面打开是空白，`#view` 里只有几个字符 | 浏览器控制台有没有报错（通常没有） | 路由 key 没对上。`pageIdOf()` 要把 `chapter/`、`concept/` 前缀剥掉再查数据 |
| 点测验，判分总落在第一题 | 检查题目的 `data-qid` 是不是重名 | 合并多书时按章节加前缀。`data-qid`、`input` 的 `name`、manifest 的 id 三处一起改 |
| "全部测验"页是空的 | 单书伴侣里那一页本来就只有一行占位文字 | 按章把题目拼起来重新渲染，不能直接搬单书的空页 |
| 图位置显示一大段 "Parse error on line…" | 找到对应 markdown 的 mermaid 代码块 | 标签里出现了 ` | ` 或半角括号。改成全角，或者把公式挪到标签外 |
| 图的形状语法坏了，比如 mindmap 不显示 | 对比清洗前后的源码 | 清洗时不能全局替换括号。只改方括号、花括号、边标签内部的 |
| 中文文件名在本地能开、Pages 上 404 | 看浏览器地址栏编码 | 链接用 `encodeURI` 包一层。本仓库的单书伴侣链接已经处理过 |
| 卡片点了不翻 | 元素上有没有 `flip` class | 检查 JS 有没有报错，通常是模板里 id 改了但脚本没跟着改 |

## 验证

| 症状 | 怎么确认 | 怎么修 |
|---|---|---|
| 报找不到 `chromium_headless_shell` | 报错路径指向 `ms-playwright/…` | 不用重装，加 `--chromium /usr/local/bin/chromium`，脚本会自动带 `--no-sandbox` |
| 某项 FAIL，但手动点完全正常 | 在无痕窗口重新走一遍同样的操作 | 十有八九是断言写死了初始状态。比如断言"应为 2/17"，前面测试已经访问过一章，实际是 3/17 |
| 控制台有 mermaid CDN 的加载错误 | 断网环境 | 属预期。图会降级成源码。要完全离线就把 `mermaid.min.js` 内联进 HTML |
| 搜索 0 命中 | 换一个更短的词试 | 搜索是子串匹配，标点、全角半角差异都会影响。也可能是那一页数据没渲染进去 |
| 进度刷新后归零 | 看 slug 有没有改过 | 进度按 `book:page` 存在 localStorage，换 slug 等于换命名空间。另外无痕模式关掉就清空 |

## 打包与部署

| 症状 | 怎么确认 | 怎么修 |
|---|---|---|
| `final` 包里还有 `_work/` | `unzip -l x.zip \| grep _work` | 模式参数写错了，或者目录名不叫 `_work`（自定义目录名脚本认不出） |
| 包特别大 | `unzip -l` 看体积集中在哪 | 多半是扫描页截图。`final` 模式会排除，`full` 模式会带上，自己权衡 |
| Pages 打开 404 | 仓库根目录有没有 `index.html` | 文件被放进了子目录。Pages 的目录设置要选 `/ (root)` |
| Pages 里以下划线开头的目录 404 | 仓库根有没有 `.nojekyll` | 没有就 `touch .nojekyll` 再推一次 |
| 改了内容页面不变 | 换无痕窗口或加 `?v=2` | Pages 有 CDN 缓存，等一两分钟 |
| 私有仓库开不了 Pages | 仓库设置里 Pages 项灰着 | 公开 Pages 需要仓库公开，或者用付费计划 |
| 推送被拒，提示文件过大 | `git count-objects -vH` | 单个文件别超 100 MB。截图压缩或者不放仓库 |

## 内容质量

| 症状 | 怎么确认 | 怎么修 |
|---|---|---|
| 页面很漂亮但读不下去 | 随便挑一章，遮住标题看能不能复述 | 精读没做到位。回去读 `_work/raw/chNN.txt`，重写这一章 |
| 测验答案和讲解对不上 | 抽 3 道题人工核一遍 | 写题和写讲解分了两遍。以讲解为准改答案，或者重写讲解 |
| 概念页之间互相指不到 | 点概念页底部的"相关概念" | 链接用了文件名而不是 manifest 里的 id，或者 id 压根不存在 |
| 学习路径顺序别扭 | 对着概念依赖图看 | 路径没按拓扑序排。依赖图里有环的话先拆环，再排 |
